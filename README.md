# Deadlock Demo Tracker

App de escritorio para Windows que lee las demos de tus partidas de Deadlock y te enseña tu historial, tus estadísticas y el detalle de cada partida.

Este repositorio solo contiene las versiones publicadas. Para instalarla:

1. Ve a [Releases](../../releases/latest) y descarga el instalador `.exe`.
2. Ábrelo. Se instala solo para tu usuario y no pide permisos de administrador.
3. Windows SmartScreen puede avisar de que la app no está reconocida, porque el instalador todavía no está firmado. Pulsa «Más información › Ejecutar de todas formas».

La app se actualiza sola cuando sale una versión nueva.
